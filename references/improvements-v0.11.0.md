기존 코드에 CI(`.github/workflows/test.yml`)와 Windows npm 래퍼 회귀 테스트가 이미 있었다. README의 오래된 Luna 제거 서술도 앞선 수정에서 제거돼 있었다. 이러한 항목은 새로 없는 기능이라고 취급하지 않고 현재 상태를 유지·보완했다.

검증: 전체 테스트 **222개 중 221개 통과, 실패 0, 실제 CLI 스모크 1개 건너뜀**. 상태 문서·스키마 생성 검사와 문서의 로컬 링크 확인도 통과했다. 최종 report 축약과 비용 미보고 보완의 관련 회귀 테스트 2개도 통과했다. 실제 벤더 호출은 실행하지 않았고, Ubuntu·Windows CI 원격 실행 결과나 커버리지 수치의 향상을 주장하지 않는다.

병렬 실행은 독립 작업의 기반이다. worktree 경쟁의 승자 선택, 변경 자동 merge, 원본 프로젝트의 승인·마일스톤 자동 통합은 포함하지 않는다. 비용은 CLI 보고값에 의존하며 미측정 비용을 추정하지 않는다. 한 라운드가 비용 상한을 넘을 수 있다. 사용법과 한계는 [operations](operations.md), 호환성 이력은 [CHANGELOG](../CHANGELOG.md)를 참고한다.
